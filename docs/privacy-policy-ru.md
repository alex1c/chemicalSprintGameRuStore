# Политика конфиденциальности — «Химический спринт»

Черновик для будущей публикации (GitHub Pages / сайт ForestMusic).
Не является юридической консультацией.

Дата черновика: 2026-09-12

## 1. Кто мы

Приложение «Химический спринт» — образовательная игра общего назначения для
запоминания элементов таблицы Менделеева. Разработчик: ForestMusic / Calculator
Platform (`com.calculatorplatform.chemicalsprint`).

## 2. Какие данные хранятся локально

На устройстве сохраняются:

- игровой прогресс (рекорды, статистика режимов, mastery элементов);
- баланс «атомов» и использование подсказок;
- ежедневный спринт и серия дней;
- достижения и посещённые материалы обучения;
- настройки (например, тактильный отклик);
- служебные счётчики рекламы (лимит rewarded за день, пауза interstitial).

Аккаунт не требуется. Собственного игрового сервера нет: прогресс не
синхронизируется на сервер разработчика.

## 3. Реклама

В приложении используется рекламная сеть Яндекса (Yandex Mobile Ads / РСЯ).

Рекламный SDK может обрабатывать технические идентификаторы устройства и
связанные с показом рекламы данные согласно политике Яндекса, чтобы загружать,
показывать и измерять рекламу.

Форматы:

- баннеры на спокойных экранах;
- редкий межстраничный показ после результата партии;
- добровольное rewarded-видео за игровые «атомы».

Реклама не является обязательной для прохождения игры. При отсутствии сети
игра продолжает работать; реклама просто может быть недоступна.

## 4. Аналитика

Подготовлена интеграция с AppMetrica. Пока production API key не активирован,
отправка аналитики может быть отключена.

После активации могут собираться обезличенные события использования
приложения (например: открытие приложения, старт/завершение режима, показ
rewarded), без имени, email, аккаунта и произвольного пользовательского текста.

## 5. Разрешения

Для работы рекламного SDK обычно требуются доступ к сети и состояние сети.
Приложение не запрашивает контакты, камеру, файлы или геолокацию ради игрового
процесса.

## 6. Дети

Приложение не позиционируется как специально предназначенное для детей.
Отдельные возрастные формы и сбор данных о возрасте не внедряются.

## 7. Контакты

Актуальные контакты и внешняя ссылка на эту политику будут добавлены в
настройках приложения при публикации релиза.

## 8. Изменения

Текст политики может обновляться. Существенная версия будет отражена в
документации релиза и/или на странице политики.
